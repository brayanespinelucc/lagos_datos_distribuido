# Borrador para el correo de entrega

**Asunto propuesto** · Entrega de plataforma empresarial para un lago de datos distribuido

Profesor:

Presento el proyecto de lago de datos distribuido para el caso de ventas e inventario. El portal reúne la arquitectura, el flujo desde los archivos de origen hasta los indicadores comerciales, y las pruebas de operación y recuperación.

Para revisar la entrega, puede empezar en el README del repositorio, abrir la guía docente y seguir el índice hasta las actas y capturas de cada prueba. Las evidencias identifican el entorno de ejecución y los componentes que quedaron preparados para un despliegue posterior. El paquete descargable permite consultarlas sin mantener encendidos los laboratorios.
